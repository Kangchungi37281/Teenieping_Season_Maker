# Teenieping_Season_Maker
태풍-티니핑 스왑을 위한 도구입니다. 개발중이며, 주로 저의 태풍-티니핑 스왑 위키를 위해 제작되었습니다. 이 도구는 원래 Kangchungi github에 있던 연도별 나무위키 태풍 템플릿에서 유래했습니다.

# 이 스왑에서 변경됨
용어 변경: 태풍->티니핑, 허리케인-> 위시캣, 사이클론->바다이(폭풍), 후지와라 효과->소용돌이 효과, 하이퍼케인->바다이티니위시

열대요란->타이니요란, 열대저기압->타이니저기압, 열대폭풍->타이니폭풍 아열대저기압:위시저기압 아열대폭풍:위시폭풍 슈퍼 태풍->슈퍼 티니핑 온대저기압->중간저기압, 몬순저기압->유지, 태풍의 눈->티니핑의 눈

## 주의사항!
인공지능으로 제작되었습니다.

이 저장소에 불만에 있다고해서 문제를 제기하지 마세요(저는 너무 복잡한 사건을 싫어합니다.)

저작권 문제나 신고가 되면 이 저장소는 비공개됩니다. 저작권 문제가 매우 심각해질 경우 해당 저장소는 제가 강제 제거할수도 있습니다.
